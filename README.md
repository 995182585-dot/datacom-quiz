# 华为数通刷题 · HCIA / HCIP Datacom

一个纯前端的刷题应用，覆盖 **HCIA-Datacom（H12-811）** 与 **HCIP-Datacom（H12-821 + H12-831）**，
支持单选、多选、判断、填空四种题型。

**题库规模：共 2009 题**

| 级别 | 题量 | 章节 | 每章题量 |
|---|---|---|---|
| HCIA-Datacom | 960 | 15 章 | 62 ~ 65 题 |
| HCIP-Datacom | 1049 | 17 章 | 50 ~ 68 题 |

题型分布：单选 1052 · 多选 407 · 判断 385 · 填空 165

## 使用

直接用浏览器打开本仓库的 GitHub Pages 地址即可。

**手机上使用（推荐）**

- **iOS Safari**：底部「分享」→「添加到主屏幕」，桌面会生成「数通刷题」图标，点开全屏运行
- **Android Chrome**：菜单 →「添加到主屏幕」

添加到主屏幕后首次打开会自动缓存全部资源，**之后断网也能用**。

## 功能

| 功能 | 说明 |
|---|---|
| **章节练习** | 按知识点分类，共 32 个章节。支持顺序练习、随机练习、只练本章错题 |
| **随机练习** | 全题库随机抽 50 题 |
| **模拟考试** | 限时答题、倒计时、交卷判分（满分 1000，600 分及格），可选 30/50/60/80 题 |
| **错题本** | 自动收集做错的题，做对后自动移出；支持重做、随机重做、清空 |
| **我的收藏** | 答题时点 ☆ 收藏，可单独练习 |
| **答题卡** | 总览所有题目作答状态（蓝=已答 / 绿=对 / 红=错），点击跳转 |
| **学习统计** | 总进度、各题型正确率、章节正确率（薄弱优先）、最近 7 天练习量、模考历史 |

其他：进度自动保存（中途退出可继续）、每题带解析、键盘快捷键（`1-4` 选项、`←→` 翻页）、移动端适配。

学习数据保存在浏览器 `localStorage`，不上传任何服务器；不同设备之间不互通。

## 关于题库来源

华为官方**不公开** HCIA/HCIP 真题题库，网上流传的「真题」多为考生回忆版或培训机构模拟题，
存在答案错误与版权问题。

本项目题库按**官方考试大纲知识点**编写，题目为原创，答案经技术核对（华为 VRP 默认值、
协议标准、子网计算等），并附带解析。题库经过一轮独立答案正确性复核（含用 RFC 4861、
ISO 10589 等原始资料验证争议点），复核发现的缺陷均已修正。

**适合作为知识点练习与自测，但不保证与真实考试题目重合。** 请以官方教材与产品文档为准。
